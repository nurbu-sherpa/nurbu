# 💻 Developer Portfolio

A **modern, responsive, and interactive developer portfolio** built with **Next.js (App Router)**, **React**, **Tailwind CSS**, and **Framer Motion**.  
Showcases projects, skills, and a working contact form.

---

## 🚀 Features

- **Modern UI/UX:** Clean, responsive, and interactive design  
- **Component-Based Architecture:** Reusable, maintainable React components  
- **Dynamic Projects Section:** Easily update projects via `data/projects.js`  
- **Contact Form:** Backend-ready API route for handling messages  
- **Animations:** Smooth transitions and interactions with Framer Motion  
- **Dark/Light Mode:** Optional toggle for user preference  
- **SEO Optimized:** Next.js built-in optimizations for faster performance  

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React, Next.js (App Router) |
| Styling | Tailwind CSS, CSS Modules (optional) |
| Animations | Framer Motion |
| Backend | Next.js API Routes |
| Deployment | Vercel |
| Data Storage | Local JSON (or optional database for messages) |

```text
